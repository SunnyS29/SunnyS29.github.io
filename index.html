# bioinformatics and data

CalcCatch

matlab · python · neuroscience

Built for my MSc research to find active neurons in calcium imaging recordings automatically. By hand that work takes months of annotation. On a hand-annotated recording it found 59% of marked neurons against the standard toolbox’s 30%.

source

Aptamer Pipeline

python · molecular diagnostics

Python pipeline that picks candidate aptamers out of raw HT-SELEX sequencing data. Aptamers are short DNA sequences that bind specific targets and are used in diagnostics and biosensors. It tracks how promising sequences change across selection rounds so candidates that only look strong in a single round get filtered out.

source

Sourdough Microbial Networks

python · bioinformatics · microbial ecology

Can microbes found together in sourdough actually coexist? Benchmarks seven methods on sequencing data from 500 starters and checks their predictions against 28 lab experiments.

source

Melbourne Cyclist Crash Explorer

duckdb-wasm · javascript · public data

Ask plain-English questions about 15,485 Melbourne cyclist crashes from 2012 to 2025 and get direct answers, charts and the raw table. Runs SQL on a static Parquet file entirely in your browser with no server.

live demo source
